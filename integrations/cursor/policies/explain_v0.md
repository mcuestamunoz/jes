# Cursor Policy — Explain v0

Non-destructive Operation validating Communication.

## Objective

> Communicate an Explanation artifact from Engineering State (+ optional Understanding).

## Difference from Research

- Research gathers/structures context → Understanding
- Explain communicates existing understanding → Explanation

Selection uses Cycle Intent signals (`explain`/`summarize`/`describe`) to keep them distinct.

## Non-goals

- No deep research pass
- No mode change
- No implementation proposals
- No Cognition doc coupling

## Command

```bash
python3 integrations/cursor/runtime/explain.py run
```
