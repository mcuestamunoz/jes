## Decision gate

When ~10–20 entries exist, answer:

1. Is Cursor enough for the daily flow?
2. Which gaps are recurring (not one-offs)?
3. Would a second tool solve a **demonstrated** gap, or only duplicate Cursor?
4. If yes — what **role** does that tool own? (not “also helps with code”)

Only then design the ecosystem. Not before.
