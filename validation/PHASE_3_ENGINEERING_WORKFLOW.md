# Phase 3 — Engineering Workflow in Practice

> **Status: not started.** Opens after JES v1.3 is closed.

## Objective

> Define how an engineer uses JES day to day to develop real projects.

This phase defines the **work system**, not the tool.

## Seed question

> **How does an engineer work with JES during a real day?**

Not “how does Cursor work.”  
Not “which commands exist.”

Rather:

```text
I arrive at the project
    ↓
I want to start working
    ↓
What do I do?
    ↓
How do I interact with Cursor?
    ↓
When does my session end?
```

## Method (same rigor as Core)

1. Hypothesis about daily flow with Cursor + JES  
2. Practice on JARVIS  
3. Evidence (field notes)  
4. Conclusion — including whether a second tool is justified (**P9**)

Field notes template will live here once Phase 3 opens.  
Do not invent the workflow in advance of practice.
